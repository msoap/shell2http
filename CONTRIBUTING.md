# Contributing

Thanks for your interest in shell2http! Please follow these rules:

1. **Issue first.** Open an issue and discuss the bug or feature before creating a pull request. PRs without a prior issue and discussion may be closed.
2. **One PR — one change.** Each pull request should fix one bug or add one feature. Don't mix unrelated changes in a single PR.
3. **Keep it simple.** shell2http aims to stay as simple as possible. If something can be done with a shell script or the environment, it will not be added to the Go code.
